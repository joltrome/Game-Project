# VM-0.6.10 Refund Chute runtime assets

These four PNGs are the approved Concept C runtime references from the
project-specific Startup Lab Work package `vm069_refund_chute_C`:

- `refund_chute_idle.png`
- `refund_chute_pre.png`
- `refund_chute_open.png`
- `refund_chute_lip.png`

They were authored as geometric pixel-grid extensions of the project's own
vending-machine visual language. The source package reports no third-party
font or image content in these runtime images. Each asset is an unscaled,
transparent 84×66 PNG intended for nearest-neighbour rendering at 1×.

The larger Work package, comparison boards, HTML viewer, SVG studies, source
scripts, and frozen gameplay screenshots are review material and are not
copied into this public repository.
